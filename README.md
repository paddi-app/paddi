## Installation

### Homebrew (macOS / Linux)

[![Homebrew Tap](https://img.shields.io/badge/homebrew-paddi--app%2Ftap-orange?logo=homebrew)](https://github.com/paddi-app/tap)

```bash
brew tap paddi-app/tap
brew install paddi
```

### pip / uv

[![PyPI](https://img.shields.io/pypi/v/paddi-cli)](https://pypi.org/project/paddi-cli/)

```bash
pip install paddi-cli
# or
uv tool install paddi-cli
```

### npm / bunx

[![npm](https://img.shields.io/npm/v/@paddi-app/paddi)](https://www.npmjs.com/package/@paddi-app/paddi)

```bash
npm install -g @paddi-app/paddi
# or run without installing
bunx @paddi-app/paddi
```

### Scoop (Windows)

[![Scoop](https://img.shields.io/badge/scoop-paddi--app%2Fscoop--bucket-blue?logo=windowsterminal)](https://github.com/paddi-app/scoop-bucket)

```powershell
scoop bucket add paddi-app https://github.com/paddi-app/scoop-bucket
scoop install paddi
```

### Winget (Windows)

[![Winget](https://img.shields.io/badge/winget-Paddi.Paddi-blue?logo=windowsterminal)](https://github.com/microsoft/winget-pkgs/tree/master/manifests/p/Paddi/Paddi)

```powershell
winget install Paddi.Paddi
```

### Go

[![Go Reference](https://pkg.go.dev/badge/github.com/paddi-app/paddi.svg)](https://pkg.go.dev/github.com/paddi-app/paddi)

```bash
go install github.com/paddi-app/paddi@latest
```
